# Cosmic Tools v3.0

Cosmic Tools is a comprehensive, privacy-centric utility suite designed for Forex traders to analyze markets and track performance. Built with local-first data sovereignty, all trading-sensitive information remains stored securely on your own device.

---

## Core Features

* **Trading Journal:** Multi-tabbed logging with custom strategy tracking, media attachments for setups, JSON import/export portability, and 16+ advanced performance metrics (equity curves, monthly histograms, win-rate distributions).
* **Market Analyzer:** A real-time data hub integrating professional market feeds, live economic calendars, technical analysis mini-charts, and news headlines powered by TradingView and FinancialJuice.
* **Risk Calculator:** A precision position-sizing tool to manage risk-to-reward ratios and enforce disciplined capital management.

---

## Tech Stack

* **Framework:** React.js + Vite (optimized build performance)
* **Styling:** Tailwind CSS (custom dark-themed space aesthetic)
* **Data Layer:** LocalStorage API (100% client-side data persistence)
* **Integrations:** FinancialJuice & TradingView widgets
